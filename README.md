# E-Commerce Sales, Customer & Product Analytics | Power BI

## 📌 Project Overview
An interactive E-Commerce Business Intelligence Dashboard developed using Microsoft Power BI to analyze sales, customers, products, orders, revenue, and business performance.

## 🛠️ Tools Used
- Microsoft Power BI
- Power Query
- DAX
- Data Visualization

## 📊 Dashboard Modules
1. Sales & Revenue Analysis
2. Customer Analysis
3. Product & Inventory Analysis
4. Orders & Payment Analysis
5. Customer Value & Retention
6. Executive Summary & Business Recommendations

## 📈 Key Business Metrics
- Total Revenue: 116.15M
- Total Orders: 500
- Total Customers: 100
- Average Order Value: 232.31K
- Repeat Customer Rate: 95.96%
- Cancellation Rate: 10.60%
